# MediKiosk v4 - SIH26-26047 aligned build

MediKiosk is a patient-facing AI clinical intake platform aligned to SIH26-26047 (Patient Case-Taking Software).

## Added in v4
- Multilingual voice + text clinical history intake
- General and AYUSH/Ayurveda Dashavidha Pariksha modes
- Consent-first intake and ABHA demo linking field
- Structured physician-ready clinical history draft
- Red-flag screening and priority guidance
- OCR document intelligence: diagnoses, medications, investigations, abnormal values, timeline dates
- Limited medication interaction flagging for physician review
- Chronological health timeline
- Doctor clinical-case review
- FHIR-ready demo export and simulated HIS/ABDM integration events
- Kiosk-friendly accessible workflow with text-to-speech prompts
- Existing appointments, messaging, profiles, doctor verification, admin audit and reports retained

Live ABDM/HIS connectivity requires official sandbox/production credentials and endpoint configuration; the included interoperability flow is a safe local demo.

Automated extraction and screening are informational aids and must be reviewed by a qualified clinician.
